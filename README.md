# 🧬 Outils & Scripting pour la Généalogie

Bienvenue ! Cette organisation regroupe un ensemble d'outils, de scripts et d'utilitaires développés, sur mon temps libre, pour automatiser, structurer et faciliter les recherches généalogiques (gestion de données GEDCOM, traitement d'archives, visualisation, etc.).

---

### 💻 Environnement & Compatibilité

* **Développement & Tests :** Les outils sont principalement développés et testés sur **macOS** (Apple Silicon).
* **Multi-plateforme :** Sauf mention contraire, le code est écrit de manière portable (Rust, Go, Python, Shell, Web, etc.) et peut s'exécuter sous **Linux** et **Windows**.

---

### 🛠️ Les Projets de l'Organisation

* 📜 **[gedcom-localizer](https://github.com/FamilyTree-nicoolaj/Genealogie-GedCom-Localizer)** : Normalise et géolocalise les lieux d'un fichier GEDCOM (généalogie).
